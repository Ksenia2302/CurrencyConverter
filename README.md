# Конвертер валют на Python (tkinter + requests)

## Описание
Прошрамма для получения актуальных курсов валют с API и конвертации между разными валютами
Реализована с использованием:
- tkinter для графического интерфейса
- requests для работы с API
- json

## Установка 
```bash
git clone https://github.com/Ksenia2302/CurrencyConverter.git
cd CurrencyConverter
pip install -r requirements.txt
